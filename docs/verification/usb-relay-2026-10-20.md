## 复现命令

在仓库根目录运行以下非硬件命令，Python 需为本机已安装的 3.11 环境：

```powershell
python -B -X utf8 -m unittest discover -s public\examples\usb-relay -p test_relay_control.py -v
python -B -X utf8 public\examples\usb-relay\relay_control.py pulse --dry-run
npm run check
npm run build
git diff --check
```

浏览器测试需要 Playwright 和本机 Edge。先在另一个终端启动开发服务（本轮端口 4398），再运行：

```powershell
$env:RELAY_PREVIEW_URL = 'http://127.0.0.1:4398'
$env:RELAY_PAGE_MODE = 'dev'
npm run test:relay-browser
```

检查已生成的静态页面时，先用静态服务器提供 `dist/client`（本轮端口 4397）：

```powershell
$env:RELAY_PREVIEW_URL = 'http://127.0.0.1:4397'
$env:RELAY_PAGE_MODE = 'build'
npm run test:relay-browser
```

测试不会自行启动服务器。开发服务不是必须固定为 4398，只需将变量指向实际地址。截图分别保存在 Git 忽略的 `test-results/usb-relay/dev/` 与 `test-results/usb-relay/build/`。

## 事实与资料复核

- 原有 `Usb_Test.py` 的 9600/8N1 与两条帧和文章一致；没有改写原文件。
- [LCUS-1 社区脚本](https://github.com/diyism/usb-controlled-relay-lcus1/blob/master/deaf_alarm.sh)确实包含相同的吸合/释放字节；它不是本板厂家兼容证明。
- [pySerial API](https://pyserial.readthedocs.io/en/latest/pyserial_api.html)支持文中参数与写入解释，并提示打开串口时 RTS/DTR 可能受系统或驱动影响；教程已加入相应边界。
- [通灵链接](https://www.tonglingrelay.com/product/1034.html?productCateId=23)确实是 12V 元件页，文章明确不能替代照片中的 5V 元件和整板说明书。
- 通用触点原理及负载注意事项对照 [OMRON 继电器资料](https://www.ia.omron.com/product/cautions/36/safety_precautions.html)，不把它作为本板额定能力或安全认证。

## 尚未验证的事项

此前原脚本完成 COM7 上三条串口指令发送。使用者已确认 PWR 亮，但尚未确认动作声音或 SW 灯变化，也没有触点通断、外部负载、上电默认状态或长期运行证据。本轮新教学程序没有硬件验收。

本地测试、GitHub 远端提交、远端 CI、Vercel 部署和实体硬件验收是不同结果。以实际 GitHub SHA 和部署记录确认后续发布状态；不能用本文的本地测试代替它们。
