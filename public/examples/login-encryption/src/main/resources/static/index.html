WEB CRYPTO / JAVA 21

一次登录请求，怎样变成密文？

浏览器先取得临时公钥，再用 ECDH 协商、HKDF 派生和 AES-GCM 加密；Java 解密并检查固定演示数据。

选择一个场景。仅使用代码中的虚构数据，无需输入账号或密码。

响应区域只显示结果，不显示私钥、AES 密钥或解密内容。每次演示重新获取挑战；同一浏览器的标签页共享会话，新挑战会替换旧挑战。

这是协议互通示例。没有真实用户库、验证码签发、Redis、登录态、权限或风控。演示数据公开固定，不能作为生产认证。请从 http://127.0.0.1:8080 打开，勿使用 file://；生产环境仍需 HTTPS。
